# Atelier Ventre

Site vitrine d'Atelier Ventre : sites web, outils d'automatisation et intelligence artificielle sur mesure.

Une seule page HTML autonome (`index.html`), sans build ni dépendance. Les pages détaillées des
réalisations (FEC vers DAS2, Bilan Ortho) sont des vues de la même page, ouvertes par `#fec-das2` et
`#bilan-ortho`.

## Voir le site

Ouvrir `index.html` dans un navigateur.

## Reste à faire avant la mise en ligne

- Relier le formulaire de contact à une messagerie (il affiche pour l'instant un message de maquette).
- Réserver le nom de domaine atelier-ventre.fr et créer l'adresse `contact@atelier-ventre.fr`.
- Remplacer les aperçus dessinés des réalisations par de vraies captures d'écran si souhaité.
